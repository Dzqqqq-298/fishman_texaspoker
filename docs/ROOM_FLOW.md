# 大厅与好友房流程

## 官方资料参考

- [PokerStars Home Games FAQ](https://www.pokerstars.com/help/articles/home-games-faq/)：俱乐部大厅与创建牌桌是分开的步骤，建桌时配置游戏、限注和人数等。
- [ClubGG October 21 Update Notes](https://www.clubgg.com/post/clubgg-october-21-update-notes)：创建牌桌区分必要设置、Advanced Options 和 Table Policies。

参考这些产品的信息结构，把基础设置直接展示，把追加、加入和带入范围放进高级选项。以下是本项目的好友房约定，不声称完全复刻某个平台，也未对其付费客户端做实际操作验证。

## 当前流程

1. 登录进入大厅，查看可用积分、当前唯一房间及最近战绩。
2. 没有房间时可以创建；基础设置包括房名、人数、时长、盲注、默认带入和特色玩法。
3. 创建者成为房主。玩家进入房间查看规则，自行带入入座。建房和等待不计时、不扣积分。
4. 两人以上就绪后，房主开始比赛，首次成功发牌启动总计时。后续自动发牌，也可本手后暂停。
5. 开赛后配置冻结；暂停期间总计时继续。房主可随时要求本手后结束。
6. 到时或手动结束时完成当前手，结算鱿鱼、退回筹码、存档战绩，释放唯一房间，所有人回到大厅。

## 对本项目的取舍

- 单个服务端状态机强制唯一房间，不只靠隐藏创建按钮。
- 固定盲注、虚拟积分、允许反复带入；时长是朋友聚会的场次时长，没有加入淘汰赛或自动升盲。
- 手机竖屏和电脑宽屏共用流程，通过宽度自适应；入座后的本人相对视角不变。
- 账号创建属于管理员工具，放在大厅；房主身份属于每场房间创建者。
- 测试覆盖并发建房、容量和规则约束、权限、计时、收尾、重启、积分守恒，以及 11 个真实网络客户端从建房到再建房的流程。遵守项目约定，不做截图或视觉巡检。
