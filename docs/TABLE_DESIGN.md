# 牌桌交互

按用户提供的 APP 截图：空座可点击，设置和记录按需展开，牌桌占主画面。保留简短文案和个人信息入口。

## 视觉与布局

- 桌布 #24594d、外场 #102b28、面板 #172c30、正文 #edf3eb、次要文字 #afc4bc、操作金 #e3c481。
- 中文采用系统无衬线（苹方 / 微软雅黑），金额使用等宽数字；房间名 18～22px，操作 14px，座位 11～13px。
- 电脑为宽牌桌，手机为纵向牌桌；固定物理座位，已入座玩家的视角旋转到下方中央。
- 默认只展示房名、时长、盲注、座位、公共牌和当前操作。设置与记录不占常驻栏位。

```text
大厅 / 房名                  设置  记录  我的
            时长 · 盲注
     空座     空座     空座
  空座       公共牌       空座
  空座        底池        空座
             本人
             手牌
          弃牌 / 跟注 / 加注
```

点击空座 → 带入弹窗 → 服务端确认座位和扣款 → 本人视角转至底部。设置/记录 → 模态抽屉 → 关闭后回到原牌桌；支持 Escape、焦点限制和焦点返回。

## 参考与取舍

- [Elite-Poker GameTable](https://github.com/opadips/Elite-Poker/blob/main/frontend/src/GameTable.jsx)：设置与历史各自按需显示。
- [Elite-Poker usePlayerPositions](https://github.com/opadips/Elite-Poker/blob/main/frontend/src/hooks/usePlayerPositions.js)：本人底部的相对座位视角。
- 用户提供的 APP 截图：直接空座入座，记录侧面展开。

本项目使用固定座号与完整空座列表，不按当前入座人数重新均分位置；不复制参考项目源码或图片。只保留一个房间，不加入聊天、广告、付费皮肤等无关功能。

## 验证

规则测试覆盖指定座位、重复/失效请求、非法编号、抢座不扣款、空位复用、重启后座号保留，以及 11 个客户端选座联机。布局函数测试覆盖 2～11 座的本人视角和窄屏座位边界。浏览器功能测试使用 1440px 与 375px 两个独立会话，验证实际选座、抽屉默认关闭、Tab 焦点循环、Escape 返回焦点、记录读取及结束结算；没有截图或视觉巡检。
